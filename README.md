## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/your-username/react-native-projects.git
```

2. Navigate to a project folder

```bash
cd Project-Name
```

3. Install dependencies

```bash
npm install
```

4. Start the Expo development server

```bash
npx expo start
```
